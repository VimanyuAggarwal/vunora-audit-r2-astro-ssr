Este blog incluye varias características clave:

- Soporte w13dev2 para modo oscuro

- Tabla de contenidos

- Soporte para markdown con componentes personalizados

- Resaltado de sintaxis

- Estimación de tiempo de lectura

- Soporte multilingüe
